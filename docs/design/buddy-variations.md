# 눈여우 버디: 스타일 제안 3종

2026-11-14. 이전에 선택한 눈여우의 흰 몸, 네이비 목도리, 노란 집 열쇠를 유지하고 표현 방식을 비교했다. 세 시안은 내장 이미지 생성 도구로 만든 검토용 PNG이며 서비스 화면에 적용하지 않았다.

| 시안 | 표현 | 적합한 위치 | 판단 |
| --- | --- | --- | --- |
| A SIMPLE | 외곽선을 덜어낸 간결한 2D, 큰 형태와 작은 표정 | 앱의 빈 상태, 작은 안내, 알림 일러스트 | 기본 앱 캐릭터로 우선 추천. 작은 크기로 단순화하기 쉽다. |
| B SOFT | 무광 장난감 같은 3D, 부드러운 조명과 볼륨 | 가입 환영, 예약 완료, 랜딩·홍보 | 친근한 존재감이 크다. 최종 도입 시 표정·각도별 자산 관리가 필요하다. |
| C CLUB | 가는 손그림 선, 종이 질감, 편안한 표정 | 크루 배지·스티커·굿즈, 커뮤니티 콘텐츠 | 동아리의 개성을 살리기 좋다. 아주 작은 아이콘은 별도 단순화가 필요하다. |

브랜드 대표 그림으로는 B도 매력적이지만, 달력·관리 화면의 간결함을 우선하면 A가 가장 무난하다. 어떤 안이든 캐릭터는 빈 상태·완료·대기 등의 보조 역할로 쓰고 예약 현황이나 숫자보다 크게 강조하지 않는다.

## 레퍼런스와 해석

- Duolingo는 위젯에서 캐릭터의 표정과 자세를 상태에 맞게 확장한다. 여기서는 표정 체계를 적은 형태로 확장하는 원칙을 A에 참고했다. [공식 위젯 디자인 소개](https://blog.duolingo.com/widget-feature/)
- Pentagram의 Reddit 작업은 기존 2D 캐릭터를 3D 형태와 여러 표정으로 체계화한 사례다. 2023년에 발표된 정착 사례로, 최신 유행으로 단정하지 않고 B의 입체 캐릭터 시스템을 검토하는 근거로 참고했다. [공식 프로젝트](https://www.pentagram.com/work/reddit)
- IPX는 2025년 Ketnipz 협업에서 공감·위로와 고유한 일러스트·이야기를 강조했다. 편안한 캐릭터를 크루의 일상에 연결하는 방향을 C에 참고했다. 선의 굵기와 종이 질감은 우리 서비스용 디자인 해석이다. [공식 발표, 2025-05-20](https://linefriends.com/en/media/ketnipz)
- 2026년 11월 LITTLE RIIZE minini 사례는 작은 캐릭터, 표정·세계관과 굿즈 확장 사례로 살폈다. 기존 캐릭터의 외형이나 소품을 복제하지 않았다. [공식 발표, 2026-11-04](https://linefriends.com/en/media/ipx-raijeu-riize-wa-hamggehan-riranini-little-riize-minini-gonggae)

이는 최근 사례와 기존 브랜드 시스템을 참고한 세 가지 제안이며, 업계 전체의 유행을 통계로 입증한 분류는 아니다.

## 로컬 산출물

생성 모드: 내장 image_gen. 이전 대화에서 생성한 캐릭터 비교표의 왼쪽 눈여우만 정체성 참고로 사용했다. 타사 캐릭터 이미지는 생성 입력으로 사용하지 않았다.

- `output/design/buddy-variations/a-simple.png`
- `output/design/buddy-variations/b-soft.png`
- `output/design/buddy-variations/c-club.png`
- `output/design/buddy-variations/prompts.json`: 실제 생성 프롬프트 공통부와 시안별 지시

이미지와 프롬프트 원본은 로컬 검토 산출물로 보관하며, 대용량 PNG를 코드 저장소나 제품 번들에 포함하지 않는다. 최종안 선택 후 작은 크기 가독성, 투명 배경, 대비, 일관된 표정 세트를 별도로 다듬는다.
