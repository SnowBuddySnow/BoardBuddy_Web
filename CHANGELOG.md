# Changelog

Notable BoardBuddy Web changes are recorded here. Versions follow Semantic Versioning.

## [1.0.0] - 2026-08-01

### Added

- Operations Center entry points and role-aware crew/event management.
- Manager groups, crew-scoped event access, participant management, and protected external chat links.
- Event application opening times, policy views, activity filters, self-organized events, and development sample data.
- Season-room availability states and season-aware reservation emphasis.
- Phone verification, user-type onboarding, notifications, and improved pending-crew onboarding.
- Persistent sessions using backend-issued refresh tokens.

### Changed

- Renamed the party-facing product language to the broader event terminology.
- Reworked the home event summary and event detail information hierarchy.
- Derived KUSBF affiliation from an approved school association.
- Deprecated the Bus and Slope shortcuts pending a redesigned experience.

### Fixed

- Constrained and made planning-mode explanations keyboard and touch accessible.
- Hid inactive season-room reservation controls while preserving a clear unavailable state.
